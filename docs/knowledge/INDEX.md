## Systems

The current contract of each system. Read before changing the system.

- [provider-adapters](systems/provider-adapters.md) — the OpenAI adapter in `gateway-providers` behind `ChatModelPort` (GW-01, GW-02): one POST with the configured key and the gateway request ID as `X-Client-Request-Id`, status, headers and bytes to pure functions, every upstream failure a sealed `ProviderFailure` and one error row; no retries, one `Mono.timeout` deadline, 503 only when nothing was sent, no provider `message` or key in a response or log, unknown members verbatim both ways, estimated usage flagged; loopback bind and `Host` check until GW-04. Streaming: a cold flow of sealed events, chunk by chunk, first-byte, idle and total deadlines from one `Flux.timeout`, commit at the first frame, an SSE error frame and a clean end after it, one end-of-stream report, no pooled buffer past the copy; a slow reader meets two limits, `ClientStallHandler` on the connection and `idle-timeout` on the stream.
- [local-stack](systems/local-stack.md) — seven dev services in `deploy/compose.yaml` (Postgres, Redis, Redpanda, OTel collector, Jaeger, Prometheus, Grafana) on `127.0.0.1` ports from `LLMGW_*_PORT` with the CLAUDE.md defaults, project `llmgw` or `COMPOSE_PROJECT_NAME` from `deploy/.env` (FND-02); OTLP to Jaeger and Prometheus, Grafana datasource UIDs `prometheus` and `jaeger`; Grafana on 3301 with anonymous Admin answering only `Host: 127.0.0.1`; `tools/smoke/stack-check.sh` (12 checks) proves it, and `scripts/preflight.sh` warns about stack ports held by other processes; `test-support` singletons with the same images (`StackContractTest`), integrationTest-only (ARCH-11 and `checkTestSupportClasspath`).
- [mock-provider](systems/mock-provider.md) — deterministic OpenAI- and Anthropic-shaped fake on :8090 (FND-03): same request, same content and usage; provider-exact SSE flushed per event; per-model scenarios under `/__mock` (steps consumed exactly once); every non-admin request counted and journaled once, credentials kept only as an 8-hex SHA-256 fingerprint; runs as a process or a Testcontainers image (`integrationTest` suite); every wait is a Reactor timer, so BlockHound guards the code after it; reads of `/__mock/stats` and `/__mock/requests` wait up to `mock.journal.read-wait` for in-flight entries.
- [request-context-and-errors](systems/request-context-and-errors.md) — gateway-generated UUIDv7 `x-request-id` on every response, validated and echoed `x-client-request-id`, every error as the four-member OpenAI envelope from one `ErrorWebExceptionHandler` in `<app root>.error` (FND-04, ARCH-10); the envelope is always written before commit, a stackless stand-in aborts after commit, and neither logged throwables nor Reactor Netty's line carry the query string; `gateway-app`'s tests run under BlockHound and the seeded DRBG passes on the event loop.

## Patterns

- [cold-event-flow-commits-at-first-frame](patterns/cold-event-flow-commits-at-first-frame.md) — a stream is a cold `Flow` of sealed events ending in one terminal event, owned by the response subscription; a named `Started` event marks the first frame, the commit point, so a failure before it reaches the one mapper as a status (Spring's `ChannelSendOperator` bypasses the write on a first-signal error) and after it becomes an in-band frame; headers are set at `Started`, and a once-only `onEnd` reports how it ended (GW-02).
- [copy-and-release-pooled-buffers-before-a-flow](patterns/copy-and-release-pooled-buffers-before-a-flow.md) — turn each pooled `DataBuffer` into bytes and release it in the operator that receives it, because `asFlow`'s channel has no `onUndeliveredElement` and `doOnDiscard` never runs for it, so anything pooled in it leaks on cancel; prove it with `ResourceLeakDetector` at `PARANOID` and a deliberate violation (GW-02).
- [typed-core-with-json-extras](patterns/typed-core-with-json-extras.md) — domain types keep typed fields only for what the gateway reads and an `extras: JsonValue.Object` at every level for the rest, so unknown members pass through a plain-Kotlin core; numbers stay text, absent differs from `null`, text-carrying types override `toString`, and a member is promoted when an item must read it (ADR-018).
- [upstream-bytes-then-pure-classification](patterns/upstream-bytes-then-pure-classification.md) — an adapter reads status, headers and raw bytes on one path for every status, under one `Mono.timeout`, then pure functions give the result or a sealed failure; no provider body reaches an exception message, failures carry no cause, and the table is tested with no socket.
- [singleton-test-containers-mirroring-compose-images](patterns/singleton-test-containers-mirroring-compose-images.md) — one Kotlin `object` per backing service holding a Testcontainers container started in a synchronized `lazy` and never stopped (Ryuk removes it); images in `StackImages`, kept equal to `deploy/compose.yaml` by a Docker-free test; isolation per test class is the consumer's; composition over a base class, and no Spring context can stop it.
- [raw-sse-frames-flushed-per-event](patterns/raw-sse-frames-flushed-per-event.md) — provider-exact SSE frames built as strings in pure code (`data: <json>\n\n`, `data: [DONE]\n\n`, `event: <type>\ndata: <json>\n\n`) and written through a `BodyInserter` calling `writeAndFlushWith`, one inner publisher per event; waits on a Reactor timer; errors after the first frame cannot change the status; never swallow `CancellationException`. Revised for GW-02: `Flow<ByteArray>`, `asFlux(context)` keeps MDC, no headers on the builder, a clean end after an in-band error.
- [one-error-funnel](patterns/one-error-funnel.md) — every failure becomes a sealed `GatewayError`, one exhaustive core table gives status/type/code/message, one `WebExceptionHandler` in `<app root>.error` writes the OpenAI envelope; no `@ControllerAdvice` (ARCH-10). Revised after the FND-04 review: always write before commit, log a copy without Reactor's checkpoint, pin the handler bean set.
- [request-context-coroutine-element](patterns/request-context-coroutine-element.md) — the first `CoWebFilter` installs per-request values as a coroutine context element plus `MDCContext`, mirrored in an exchange attribute for the exception handler; core takes values as parameters.
- [architecture-rule-with-violating-fixture](patterns/architecture-rule-with-violating-fixture.md) — each Konsist rule is a function over a scope, applied to the real modules (must pass) and to an uncompiled fixture that breaks it (must fail), so no rule can go silently vacuous.

## Bugs

- [adapter-broken-chunked-framing-raised-as-a-bug](bugs/adapter-broken-chunked-framing-raised-as-a-bug.md) — a bad chunk size or an over-long chunk line raises a runtime exception `OpenAiTransportFailures` rethrows as a bug: a 2xx gives 500, `internal_error` replaces `upstream_error` after commit, and in the drain an `internal_error` frame follows `[DONE]`; `complete` shares the hole (medium, fixed in GW-02: any error from a body is a stackless `IOException`, and nothing follows a terminal frame).
- [first-frame-on-a-closing-channel-leaves-the-stream-flow-running](bugs/first-frame-on-a-closing-channel-leaves-the-stream-flow-running.md) — a first frame sent between channel close and `terminate` fails with `AbortedException`, `SseBodyInserter` swallows it and nothing cancels the flow: no end-of-stream report, and the provider call runs until `idle-timeout` (medium, fixed in GW-02: the inserter ends the flow itself).
- [client-write-timeout-cuts-a-slow-client-that-is-still-reading](bugs/client-write-timeout-cuts-a-slow-client-that-is-still-reading.md) — `WriteTimeoutHandler` counts queue wait, so a client reading steadily below queued bytes over the timeout is closed, against "nothing is dropped"; far from normal token streams (low, fixed in GW-02: `ClientStallHandler` measures write progress; its Revision says what remains, a slow reader on `idle-timeout`).
- [adapter-bad-provider-content-type-gives-500](bugs/adapter-bad-provider-content-type-gives-500.md) — a provider `Content-Type` Spring cannot parse makes `toEntity` raise `InvalidMediaTypeException`, which the adapter does not catch, so any status, a paid 200 included, gives 500 `internal_error` with the header value in the ERROR log; drop the header before reading (medium, fixed in GW-01: the adapter drops the header before the body read).
- [noleak-test-canary-key-never-reaches-the-adapter](bugs/noleak-test-canary-key-never-reaches-the-adapter.md) — `NoLeakIntegrationTest`'s `sk-canary-key` is overridden by `MockBackedTest`'s dynamic property, which registers last, so the "no key in the log" check is vacuous; its 5xx assertions can also run before the mapper's ERROR line (medium, fixed in GW-01: the canary is the real key, and its fingerprint is asserted).
- [completion-text-in-spring-encoder-debug-log](bugs/completion-text-in-spring-encoder-debug-log.md) — `ChatHandler` sends a tree through `JacksonJsonEncoder`, which logs the value, so `logging.level.web=debug` puts the first 100 characters of each completion in the log; write bytes instead (medium, fixed in GW-01: `ChatHandler` writes bytes).
- [usage-count-overflow-gives-500-on-a-paid-answer](bugs/usage-count-overflow-gives-500-on-a-paid-answer.md) — token counts whose sum overflows a `Long` pass the reader, then `Usage.totalTokens` throws in the writer: 500 on a paid answer; treat them as omitted usage (low, fixed in GW-01: counts that overflow are omitted usage).
- [json-value-default-tostring-prints-prompt-text](bugs/json-value-default-tostring-prints-prompt-text.md) — `JsonValue.Text`, `Array`, `Object` and `Usage` keep the data class `toString`, against ADR-018, so logging any `extras` prints prompt text; nothing logs one today (low, fixed in GW-01: they print sizes).

- [provider-key-with-newline-passes-startup-then-every-call-503](bugs/provider-key-with-newline-passes-startup-then-every-call-503.md) — a key with a trailing newline passes `toAdapterConfig`, Netty rejects the header per request, and every call is a 503 with health UP, the shape ADR-GW-01-012 rejected (low, fixed in GW-01: refused at startup).
- [arch-12-misses-typealias-declared-in-config](bugs/arch-12-misses-typealias-declared-in-config.md) — a typealias of the adapter declared in `.config` and imported by a handler passes ARCH-12; ARCH-6 closed this class of hole, and the fixture has no alias case (low, fixed in GW-01: an exported alias fails the rule).
